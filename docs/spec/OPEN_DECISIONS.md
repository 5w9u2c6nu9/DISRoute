# Open Decisions

These are intentionally unresolved. Maintain abstraction boundaries until selected/verified.

1. Avalonia docking/window framework that satisfies multi-monitor, floating, mixed-DPI and persistence requirements.
2. Desktop/mobile map renderer and base-map provider(s), including offline tile strategy.
3. Routing provider/engine and live traffic provider; apparatus restriction capability varies by provider.
4. Production PostgreSQL HA stack, quorum/witness/fencing implementation and exact deployment hardware.
5. Object/document storage implementation and backup topology.
6. Actual current Windows-server DataGate source profile/config and exact read-only migration path.
7. Exact conventional radio dispatch console/base/consolette/gateway, channel programming and signaling interfaces.
8. Exact 9-1-1 call-handling equipment/PSAP integration interface.
9. Exact recording platform model/software/API and supported metadata/playback interface.
10. External AIS provider for initial marine traffic.
11. Future local AIS receiver hardware/ingest protocol.
12. External traffic provider and municipal/local feed availability.
13. Weather/tide/current provider(s).
14. Push/pager/email notification providers.
15. Payroll/time-export target(s).
16. External electronic/digital-signature provider(s), if required beyond DISRoute attestation/signature model.
17. Exact production capacity/availability requirements and agency hardware budget before final HA sizing.
18. Final v1 feature cut line for deployment pilot after first integrated prototype is visible.
