# Visual and Interaction Reference Notes

This document describes the supplied visual references without embedding source screenshots into the new project.

## Desktop Classic reference

Use as inspiration for:

- dense framed form layout;
- thin borders;
- compact field labels/inputs;
- top menu/command-strip character;
- data grids and activity rows;
- minimal decorative whitespace;
- functional small typography;
- familiar public-safety CAD density;
- strong inline status-color language.

Modernize with responsive scaling, accessibility, keyboard navigation, dock/floating windows, multi-monitor support, collaboration presence, theme tokens, alert clarity and provider-aware panels.

## Mobile/tablet reference

Use only as interaction inspiration:

- large immediate status buttons;
- strong semantic colors;
- dense current-call information;
- shallow navigation;
- rugged/tablet usability.

Do not replicate the old exact button arrangement, layout, typography or screen structure.

## Backend/menu reference

Treat as feature-inventory inspiration: dispatch/history inquiry, incident/report records, personnel/scheduling, prevention/inspection/permits, address/premise, inventory/equipment, hazmat/investigations, security/config, messages/bulletins, interface controls and AVL administration. Reorganize as role-based searchable Operations Center modules.
