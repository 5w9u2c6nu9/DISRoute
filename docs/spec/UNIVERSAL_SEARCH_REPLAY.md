# Universal Search, History, Replay, and Records Export

## Universal Search

One permission-filtered search surface across:

- incident number / external IDs;
- address/premise;
- unit/apparatus;
- person;
- radio ID;
- document/form;
- inspection/permit;
- preplan/CRG;
- hydrant/GIS assets;
- MMSI/vessel;
- messages where policy permits.

Show fast exact results first while broader full-text domains may progressively load.

## Replay

Replay reconstructs what DISRoute knew at time X, including:

- incident location/nature/priority/narrative available then;
- assignments/statuses;
- personnel/crew/radio mapping effective then;
- AVL/AIS observations with freshness;
- map objects/road closures;
- station alert/print/delivery events;
- provider alerts;
- preplan/CRG/config versions then;
- radio/telephone recording references;
- messages where retention/permissions allow.

Differentiate:

- KNOWN — information present in DISRoute at that time;
- OBSERVED — external sensor/provider observation;
- CORRECTED LATER — later correction/reconciliation.

## After-action package

Permissioned package options can include summary, CAD timeline, unit status, AVL tracks, map, assignments, station alert/print history, preplans/CRGs referenced, recording references, personnel, and sensitive premise data according to policy.

## Records package

Records/eDiscovery export gathers releasable CAD, narratives/activity, unit timestamps, attachments, 9-1-1 references, recording references, AVL history, messages, reports and corrections. Apply classification/redaction/legal-hold/retention rules and audit every export.
